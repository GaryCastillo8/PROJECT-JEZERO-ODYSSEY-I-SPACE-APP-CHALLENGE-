# PROJECT-JEZERO-ODYSSEY-I-SPACE-APP-CHALLENGE-
This is the solution for the challenge: Interplanetary Survival Guide: Martian Map
1. To open the interface open the HTML file "PROJECT-JEZERO".
2. To see the explorations routes open the file "Jezero_Expedition_Proposal_EN"
3. To see the guide for the astronaut open the .zip file and then open "index" an HTML file.
4. To see the manual or extra documentation open the pdf file "PROJECT JEZERO ODYSSEY I.pdf"
5. To se the 3D model, topography, radiation and the Martian Station open the .txt file and copy the Google Drive link and download the folder, then open "Start Project Jezero" executable file.
